Data engineering + ML · Live

Football analytics pipeline & match predictor

An automated pipeline over 32,000+ matches from 8 European leagues: daily ingestion from CSV files and a REST API, dbt models with data tests, and an Elo + Poisson model that publishes predictions before kickoff. Backtested on 8,748 matches, it reaches 51% accuracy and closes about 80% of the gap between a naive baseline and bookmaker odds.
